# 🎓 노션 학생 동기부여 대시보드 위젯 (v2)

노션(Notion) 페이지에 `/embed`하여 학생 개개인의 **과제 수행률(오늘+누적 듀얼), 출석률, 목표 진도율, 편의점 상품권 100원 적립(선생님 검사 연동)**을 게임처럼 보여주는 반응형 웹 대시보드 위젯입니다.

---

## ✨ 핵심 기능

1. **🏪 편의점 모바일 상품권 보상 시스템**:
   - 하루 할당된 과제를 모두 완료하고 선생님 검사를 받으면 **+100원씩 적립**
   - 현재 누적 금액 / 목표 금액(5,000원 등) 실시간 프로그레스 바
   - 목표 달성 시 축하 폭죽(Confetti) 효과
2. **📝 위젯 내 실시간 집숙제 체크리스트**:
   - 학생이 숙제 항목을 클릭할 때마다 수행률 게이지가 실시간으로 차오름
   - 100% 자가 완료 시 **축하 폭죽(Confetti) 🎉과 "선생님 검사 대기중 ⏳" 황금빛 배너** 표시
3. **📊 3대 핵심 학습 지표**:
   - 🎯 **과제 수행률 (듀얼 표시)**: 오늘 과제 완수율 (%) + 이번 달 누적 성실도 (%)
   - 📅 **출석률**: 출석률 (%) 및 연속 출석(Streak) 불꽃 배지 🔥
   - 🚀 **목표 진도율**: 코스 진도율 (%) 및 현재 챕터
4. **⚙️ 간편한 노션 임베드 링크 생성기**:
   - 위젯 우측 상단 ⚙️ 아이콘을 누르면 학생 이름, 숙제 항목, 적립금 등을 입력하고 바로 노션 링크를 복사할 수 있습니다.
5. **🌓 Notion 다크 / 라이트 모드 지원**:
   - 노션의 테마 설정에 맞춰 자동으로 전환되거나 수동으로 전환 가능합니다.

## 🚀 1분 만에 무료 배포하기 (GitHub Pages)

1. GitHub에서 새 Repository(저장소)를 만듭니다 (예: `notion-widget`).
2. 이 폴더의 파일 3개(`index.html`, `style.css`, `app.js`)를 업로드합니다.
3. GitHub 저장소의 **Settings → Pages** 메뉴로 이동합니다.
4. **Branch**를 `main`으로 선택하고 **Save**를 누릅니다.
5. 1분 뒤 무료 웹 주소가 생성됩니다:
   `https://[내깃허브아이디].github.io/notion-widget/`

## 📝 노션(Notion)에 넣는 방법

1. 학생 노션 페이지에서 `/embed` 또는 `/임베드`를 입력합니다.
2. 배포된 주소에 학생 데이터를 덧붙여 입력합니다.

### 📌 학생별 맞춤 URL 예시:
```
https://[내아이디].github.io/notion-widget/?name=김철수&reward=3400&target=5000&streak=7&cRate=94&cDone=17&cTotal=18&att=95&prog=72&chapter=Chapter+8&tasks=쎈수학 50~55p B단계 홀수번,영어 단어 Day 3,오답노트 정리&hwDone=3
```

### 🔑 URL 파라미터 안내:
* `name`: 학생 이름
* `streak`: 연속 과제 달성 일수 (회)
* `reward`: 현재 누적 금액 (원)
* `target`: 목표 상품권 금액 (기본 5000)
* `tasks`: 오늘 집숙제 항목 (쉼표 `,` 로 구분)
* `hwDone`: 현재 완료된 과제 수
* `cRate`: 누적 과제 완수율 (%)
* `cDone`: 누적 완료 횟수
* `cTotal`: 누적 총 과제 횟수
* `att`: 출석률 (%)
* `prog`: 목표 진도율 (%)
* `chapter`: 진도 상세 문구 (예: `Chapter 8`, `수학 3단원`)
* `theme`: `dark` 또는 `light` (선택 사항)
